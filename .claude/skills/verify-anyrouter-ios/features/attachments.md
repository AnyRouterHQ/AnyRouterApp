# Attachments

The Add button in the composer opens a menu with photo, camera and file items. They are visible but disabled under a "Coming soon" section.

## Sub-features

- `attach-menu` the Add menu opens and shows the disabled items.

## How to get to it (user POV)

- Tap the round button labeled `Add` next to the composer.

## Driving it with the journeys harness

Preconditions:

- Demo launch.

- **Menu.** Tap `Add`. Buttons `Attach photo`, `Take photo`, `Attach file` exist and are not enabled. A model with the reasoning capability also shows the `Enable thinking` toggle.
- **Status.** The feature is not built, so there is no journey. Verify only that the surface stays and stays disabled.

## Gotchas

- Demo models do not advertise the reasoning capability, so the thinking toggle does not appear in demo data.
- Do not describe attachments as working.
